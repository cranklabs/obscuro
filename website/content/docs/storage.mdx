## Directory Location

`.obscuro/` always lives at the root of your git repository. Obscuro finds it by walking up from your current directory, just like git finds `.git/`.

## Permissions

Everything is locked down by default:

| Path                              | Mode |
| --------------------------------- | ---- |
| `.obscuro/`                       | 0700 |
| `.obscuro/config.json`            | 0600 |
| `.obscuro/secrets.json`           | 0600 |
| `.obscuro/namespaces/`            | 0700 |
| `.obscuro/namespaces/<name>.json` | 0600 |

## config.json

```json
{
  "salt": "<base64-encoded-32-byte-salt>",
  "verify": "<base64(nonce || ciphertext)>"
}
```

- `salt` — random bytes for Argon2id key derivation
- `verify` — encrypted `"obscuro-verify"` string used to check your password

## secrets.json

```json
{
  "DB_PASSWORD": "<base64(nonce || ciphertext)>",
  "API_KEY": "<base64(nonce || ciphertext)>"
}
```

A flat key-value map. Each value is `base64(12-byte-nonce || AES-256-GCM-ciphertext)`.

This file holds the `default` namespace, including secrets created before
namespace support. Named namespaces use separate files at
`.obscuro/namespaces/<name>.json` with the same flat-map format. They share the
salt, verification token, and master password from `.obscuro/config.json`.
No migration of existing files is needed. See [Namespaces](/docs/namespaces).

## Git

The config and all namespace files are safe to commit with a strong master
password. Secret values are encrypted, but secret names and namespace names are
public metadata.
