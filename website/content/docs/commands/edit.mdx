title: obscuro edit
description: Edit a secret in your text editor
---

## Usage

```sh
obscuro edit KEY
```

Decrypts the secret, opens it in your `$EDITOR` (defaults to `vi`), and re-encrypts it when you save and close.

Use `obscuro edit KEY -n production` to edit a secret in a
[namespace](/docs/namespaces). Without `-n`, only `default` is used.

## Example

```sh
EDITOR=nano obscuro edit API_KEY
```
