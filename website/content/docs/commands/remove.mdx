---
title: obscuro remove
description: Delete a secret from the vault
---

## Usage

```sh
obscuro remove KEY
obscuro rm KEY
```

Deletes a secret from the selected namespace. You can also use the `rm` alias.

Use `obscuro remove KEY -n production` to remove a secret from a
[namespace](/docs/namespaces). Without `-n`, only `default` is affected.

## Example

```sh
obscuro remove DB_PASSWORD
```
