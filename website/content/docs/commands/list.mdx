---
title: obscuro list
description: List secret key names in the selected namespace
---

## Usage

```sh
obscuro list
```

Prints secret key names in the selected namespace in alphabetical order. No
password is required, and values are never decrypted.

Use `obscuro list -n production` to select a [namespace](/docs/namespaces).
Without `-n`, only the `default` namespace is listed. To list namespace names,
run `obscuro namespace list`.

## Example

```sh
$ obscuro list
API_KEY
DB_PASSWORD
TLS_CERT
```
