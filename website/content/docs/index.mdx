title: Getting Started
description: Encrypted secrets in git that your AI agents can use without reading

Obscuro keeps encrypted secrets in a `.obscuro/` directory at your git repo
root, so they live and travel with your code. It is built so that AI coding
agents can work with those secrets without the values ever showing up in their
context, logs, or commits.

An agent can list secret names without a password, reference secrets by name in
config, run commands with secrets in their environment (`obscuro run`), render
`__KEY__` placeholders straight into a deploy tool (`obscuro inject`), and store
newly generated secrets without displaying them. You keep the master password;
once it is in your OS keychain, every command runs non-interactively.

Values are encrypted with Argon2id + AES-256-GCM. The same commands work for
people, CI, Helm, Docker Compose, Kubernetes, or anything else that reads
environment variables or text config.

## Quick Start

Install it:

```sh
curl -sSL https://raw.githubusercontent.com/janklabs/obscuro/main/install.sh | bash
```

Set up a vault in your repo:

```sh
obscuro init
```

You'll pick a master password and can save it to your OS keychain, so neither
you nor your agent has to type it again.

Store a secret (you'll be prompted for the value):

```sh
obscuro set DB_PASSWORD
```

Run a command with it in the environment:

```sh
obscuro run -- docker compose up -d
```

Or inject it into templates, for example as a Helm post-renderer:

```sh
helm install myapp ./chart --post-renderer obscuro --post-renderer-args inject
```

Obscuro reads the rendered manifests from stdin, replaces `__KEY__` patterns
with decrypted values, and writes the result to stdout.
